Instruções de Compilação e Execução:

1. Compilar os Testes Unitários:
   $ make

2. Executar a Bateria de Testes (Google Test):
   $ make test

3. Gerar Relatório de Cobertura de Código (Gcov):
   $ make coverage

4. Executar Verificação Estática de Estilo (Cpplint):
   $ make cpplint

5. Executar Análise Estática de Código (Cppcheck):
   $ make cppcheck

6. Executar Análise Dinâmica de Memória (Valgrind):
   $ make valgrind

7. Gerar Documentação do Código (Doxygen):
   $ make docs
